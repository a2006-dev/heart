# 心迹 - Windows 打包指南

## 方法一：打包成单个 exe（快速分享）

```bash
# 1. 安装 Python 3.7+
# 2. 在 Windows 电脑上运行：
pip install pyinstaller
pyinstaller --onefile --noconsole --name "心迹" --icon=heart_icon.ico heart_monitor.py
```

生成 `dist/心迹.exe`，双击即可运行。

## 方法二：制作安装程序（推荐）

### 需要的工具

1. **Python 3.7+** — 从 python.org 下载安装
2. **PyInstaller** — 打包 exe
   ```bash
   pip install pyinstaller
   ```
3. **Inno Setup** — 制作安装程序
   - 下载: https://jrsoftware.org/isdl.php
   - 安装时勾选 "Chinese Simplified" 中文语言包

### 打包步骤

```bash
# 第1步：把 heart_monitor.py 打包成 exe
pyinstaller --onefile --noconsole --name "心迹" --icon=heart_icon.ico heart_monitor.py

# 第2步：把生成的 dist/心迹.exe 复制到脚本目录
copy dist\心迹.exe .

# 第3步：双击 setup_心迹.iss（会自动打开 Inno Setup）
# 点击 "Compile"（编译）
```

### 编译完成后

生成 `Setup_心迹_v2.5.exe`，这就是安装程序。
